Libraries

One discovery library per user, per enabled type. Each is visible only to the user it belongs to.

Music uses symbolic links, because Jellyfin does not play .strm files in music libraries. On Windows this needs Developer Mode or a service account with the privilege.

Behaviour

Playback events fire constantly. This coalesces a whole session into a single refresh.
Lower values trade a little predicted relevance for a more varied list. There are no per-genre weight sliders: the ranker learns each user's weights from their own history.
Lets Jellyfin identify generated entries by exact TMDB/IMDb id instead of guessing from a folder name.
